# Четыре сезона

Лаунчер Windows x64 для Minecraft 1.21.1 / Fabric: русский интерфейс, анимированный фон, музыка и подписанные обновления сборки.

## Скачать

[Выпуски и файлы для друзей](https://github.com/dmitfun-bot/four-seasons-launcher/releases/latest)

Скачайте `FourSeasons-Windows.zip`, распакуйте целиком и запустите `FourSeasons.exe`. Введите ник (3–16 латинских букв, цифр или `_`), нажмите обновление. Кнопка «Играть» доступна после проверки файлов и ответа сервера. При запуске игра подключается автоматически. Первый запуск требует интернет для Java и Minecraft.

## Обновления и сервер

Кнопка Aternos открывает панель: владелец или друг с правом запуска включает сервер в браузере. Готовность проверяется каждые 10 секунд. Автоматический запуск Aternos без браузера не реализован.

Владелец работает в отдельной локальной панели: добавляет/убирает моды в кандидате, проверяет зависимости, тестирует игру и обновляет серверные моды на Aternos. После этого собирает подписанный выпуск и вручную публикует файлы в GitHub Releases как Latest. Друзья увидят обновление в течение минуты. Личные клавиши и карты сохраняются.

Блокировка старой сборки действует в этом лаунчере; сервер не запрещает все сторонние клиенты по номеру сборки. Обновление программы выполняется скачиванием нового ZIP.

## Исходники и проверки

`FourSeasons-source.zip` в выпуске содержит Python-исходники, инструкции и тесты. Выполнены 18 автоматических проверок, чистая установка сборки, установка Java/Fabric, запуск готового EXE и подключение тестовой игры к локальному серверу. Подключение друга с другого ПК через этот выпуск пока не проверено.

Ключ подписи хранится только у владельца и не публикуется. Список модов и сведения об авторах находятся в выпуске. Minecraft скачивается отдельно с официальных источников. Независимый проект, не официальный продукт Mojang/Microsoft.
